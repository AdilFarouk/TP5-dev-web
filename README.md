# TP5-dev-web

Application web responsive développée dans le cadre des travaux pratiques de développement web.

## Technologies utilisées
- **HTML5** : Structure de la page
- **Bootstrap 5** : Interface utilisateur et design responsive
- **JavaScript (Vanilla)** : Interactivité et scripts de vérification
- **CSS3** : Styles personnalisés
